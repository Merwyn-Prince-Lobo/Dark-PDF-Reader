# PDF Viewer

A simple HTML page to upload and view PDF files in the browser with a dark mode toggle.

## Features

* Upload and view PDFs
* Dark mode toggle
* Runs entirely in the browser

## Usage

1. Download or clone the repository
2. Open `dark.html` in a browser
3. Select a PDF file to view
4. Toggle dark mode if needed
